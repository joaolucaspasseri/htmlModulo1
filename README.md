# 💻 Curso de HTML e CSS — Módulo 1

Este repositório faz parte do meu aprendizado no curso de **HTML + CSS**, onde estou desenvolvendo minhas habilidades em **estruturação de páginas web** e **estilização com CSS**.  
O curso é dividido em **5 módulos**, e este repositório representa o **Módulo 1**.

---

## 📚 O que tem aqui

Dentro deste repositório, você vai encontrar uma pasta com exercícios e atividades práticas realizadas durante o curso.  
Esses exercícios mostram o que aprendi até agora, como:

- Estrutura básica de um documento HTML (`<html>`, `<head>`, `<body>`);
- Uso de tags semânticas;
- Inserção de imagens, links e listas;
- Aplicação de estilos com CSS (cores, fontes, alinhamentos, etc.);
- Organização de arquivos e pastas para projetos web.

---

## 🧠 Objetivo

O objetivo deste repositório é **documentar minha evolução** no aprendizado de HTML e CSS, além de servir como um **portfólio de estudos**.  
Cada exercício reflete uma etapa importante na construção do meu conhecimento sobre o desenvolvimento web.
